# Fintech UX/UI Case Study
### Improving the Digital Banking Experience

**Project type:** Independent UX/UI design project

**Focus:** Fintech, digital banking, user experience and product design

**Tools:** Figma, Adobe Illustrator and Photoshop (as used)

---

## 1. Project Overview

This project explores how digital banking applications can improve the way users interact with, understand and manage their finances.

The aim is to investigate user needs, identify opportunities for improvement and develop an intuitive digital experience.

## 2. The Problem

Financial applications can sometimes overwhelm users with information, complex navigation and unclear financial data.

This project explores how these experiences could be made more accessible, intuitive and engaging.

## 3. Research & Discovery

- Investigating user needs and behaviours.
- Analysing existing fintech applications.
- Identifying usability issues and opportunities.
- Exploring how visual design influences financial decision-making.

## 4. Design Development

- Initial concepts and brainstorming.
- User journey mapping.
- Wireframing.
- Interface exploration.
- Prototype development.
